# HaruHaru — орієнтири для продовження роботи

Україномовний локальний PWA для корейської. Поточна версія — 2.0.0. Перед змінами прочитайте PROJECT_STATUS.md. Прямі вказівки користувача щодо обсягу роботи мають пріоритет.

## Технології й архітектура

- React + TypeScript + Vite 7, Tailwind CSS 4, Lucide React.
- React Router / HashRouter, lazy-loading сторінок.
- Dexie + dexie-react-hooks, локальна IndexedDB; обов’язкового акаунта й власного backend немає.
- Tiptap — візуальні конспекти, DOMPurify — очищення HTML, Zod — формати імпорту.
- Motion for React, canvas-confetti, оригінальний SVG-маскот Хару; звуки синтезуються Web Audio.
- speechSynthesis — окремий корейський TTS; Luxon — часові пояси; ical.js — ICS.
- Vitest + fake-indexeddb — наявні тести.

## Структура

- `src/App.tsx` — оболонка, навігація, lazy-маршрути; `src/main.tsx` — запуск і стилі.
- `src/pages/` — головна, конспекти, словник, навчання, статистика, нагороди, календар, допомога, налаштування.
- `src/components/` — спільні UI, редактор, TTS, маскот, анімації, тур, оновлення PWA.
- `src/services/` — IndexedDB, імпорт/експорт, навчальні алгоритми, TTS, переносні налаштування.
- `src/game/` — журнал XP, рівні, значки, звуки, ефекти та `design-system.css`.
- `src/calendar/` — календарні моделі, Google, ICS, свята, час, runtime та історія версій.
- `src/help/`, `src/notifications/`, `src/experience/` — інструкції, нагадування, стан знайомства/перегляду версій.
- `src/models.ts`, `src/data.ts` — навчальні схеми й демонстраційні матеріали A1.
- `public/` — іконки, приклади JSON, обробник натискання системних сповіщень.
- `docs/` — формати імпорту, календарні інтеграції, опис 2.0.

## Дизайн і UX

Soft Korean kawaii: кремова основа, лавандовий акцент, рожевий, м’ятний і персиковий як допоміжні кольори. Основні початкові кольори: #F8DCE7, #E5D9F7, #FFF7ED, #DCEBDD; текст #65576D. Поточні змінні 2.0 та адаптивні перевизначення — у `src/game/design-system.css`, який підключено після попередніх стилів.

Mobile-first, особлива увага 320–430 px, safe-area iPhone і темній темі. Текст, CTA й декор Hero мають окремі області. Анімуйте переважно transform/opacity, враховуйте prefers-reduced-motion. Звуки за замовчуванням вимкнені; не запускайте їх без взаємодії. Фактичні зміни у «Що нового?» відокремлюйте від жартів. Не описуйте нереалізовані функції як готові.

## Дані та навчальна логіка

База `haruharu`, схема v3 у `src/services/db.ts`: навчальні таблиці, settings, календарні джерела/події, ICS, inbox, rewards, badges. Міграції мають зберігати дані; не очищуйте базу й не змінюйте її назву для обходу проблем. Не переписуйте наявні генератори вправ та інтервальне повторення без потреби.

XP — сума журналу `rewards`. Нагорода й відповідь записуються транзакційно з унікальними ключами; повторна доставка, reload та повторне завершення не повинні додавати XP. Значки зберігаються в `badges`. Старі відповіді не отримують автоматичного XP. Формат JSON v1 має залишатися сумісним зі старими копіями; імпорт матеріалів додає дані. Дані браузера не входять до Git: для перенесення потрібен окремий JSON-backup із застосунку.

## PWA, календарі й безпека

- vite-plugin-pwa: manifest, generateSW, режим `prompt`, кероване оновлення через `PwaUpdatePrompt`. Не перезавантажуйте автоматично відкриті форми; не очищуйте IndexedDB при оновленні.
- Офлайн доступні збережені матеріали й кеш після повного завантаження production-версії. Не обіцяйте офлайн-TTS або push/синхронізацію закритої iPhone PWA.
- Google: офіційний GIS, лише calendar.readonly, `VITE_GOOGLE_CLIENT_ID`; access token тільки в пам’яті. Client Secret, паролі й приватні credentials у frontend заборонені.
- Apple: ICS-імпорт/експорт і публічні підписки за підтримки CORS. Приватний CalDAV — лише задокументована архітектура, не готова інтеграція.
- Календар і нагадування використовують Europe/Kyiv. Свята перевірені тільки для 2026–2027.

## Запуск і перевірки

Node.js 24 LTS або сумісний Node 22.12+, pnpm 11 (остання точна робоча версія на іншому ПК невизначена).

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

Виконуйте перевірки лише в дозволеному користувачем обсязі. У `pnpm-workspace.yaml` для esbuild є незавершене значення allowBuilds: див. PROJECT_STATUS.md; не приховуйте помилки встановлення.

## GitHub Pages

`pnpm exec vite build --mode pages` використовує `/haruharu/`. Для іншого репозиторію: `pnpm exec vite build --base=/назва-репозиторію/`. HashRouter не потребує серверних rewrite. Артефакт — `dist/`; OAuth origin не містить шляху репозиторію. Не робіть commit, push чи deploy без окремої вказівки користувача.
